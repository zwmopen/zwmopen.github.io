ZWM 社媒助手 Lite

手机优先的小红书 Userscript：当前笔记提取、复制、素材下载。
v0.2.0 · 单文件自包含 安装 / 更新脚本 查看 GitHub 源码

当前功能

  • 识别小红书当前具体笔记，并自动适配 SPA 页面切换。
  • 复制结构化 JSON、正文、图片链接、视频链接、全部媒体链接。
  • 下载当前笔记图片和视频；GM_download 失败时自动尝试备用下载方式。
  • 优先读取笔记结构化数据，降低推荐区头像、缩略图混入概率。
  • 手机端使用底部面板，非具体笔记页面自动隐藏按钮。

手机使用

先在支持 Userscript 的浏览器或脚本管理器中打开上方“安装 / 更新脚本”。安装后进入小红书网页版具体笔记，页面右下角会出现“素材”按钮。普通浏览器如果没有 Userscript 能力，打开安装链接只会显示源码。
这是个人工作流实验版。小红书页面结构变化后，提取规则可能需要同步更新；更新脚本即可继续使用。
