# 跨系统分发规则

本次沉淀不是一条孤立笔记，而是一个跨系统母节点。原则：**一份母文档作为事实源，各系统只保存自己需要调用的部分。**

## 1｜世界观 / 原则库
沉淀：
- 行动型安全感
- 当前水平不是最终版本
- 对外不自贬，对内不自欺
- 对自己好：不羞辱、不自欺、补缺口

## 2｜欲望驱动系统
沉淀：
- “我想那么牛逼”不是停在情绪强度，而要转成“怎样才能那么牛逼”。
- 欲望 → 目标状态 → 条件 → 动作 → 反馈 → 能力增长。

## 3｜个人推进系统
沉淀：
- 不足变量化
- 找当前最关键限制条件
- 动作必须推动外部现实
- 当认知边际收益为零时停止继续分析

## 4｜绝对理性系统
沉淀：
决策优先看：
- 事实
- 逻辑
- 规律
- 原理
- 趋势
- 第一性原理
- 本质
- 细节
- 量化
- 模型

而不是仅依据：
- 自卑：“我没达到”
- 自大：“别人夸我牛逼”
- 恐惧包装出的体面理由

## 5｜创业 / 搞钱系统
沉淀：
- 一人也可以先搭出公司化的交付界面。
- 先研究客户真正购买的功能，再拼装组织能力。
- 可调用：AI、SOP、自动化、外包、合作方、标准化流程。
- 不等待“有团队”才开始组织化行动。

边界：组织化表达不等于虚构事实；不能通过欺诈客户建立信用。

## 6｜AI 复盘系统
新增检测器：
- “还没准备好”检测
- “经验不足”变量化
- 恐惧合理化检测
- 思考爽感检测
- 长期重复课题 → 必须产出新机制或现实动作

## 7｜第二大脑 / Git
结构：
- 母文档
- 原则卡
- 模型
- 检测器
- 对话日志
- 选题池

## 8｜认知自媒体 / 选题系统
从同一母节点衍生多个内容，不重复保存全文。每个选题只抽一个矛盾、一个模型或一个案例。

## 调用规则

遇到“我不行 / 我不够 / 我不敢 / 我还没准备好”时：

`自欺检测器 → 目标身份现实化模型 → 个人推进系统 → 当天现实动作`

遇到“别人觉得我很牛逼 / 我是不是太自大”时：

`对外不自贬、对内不自欺 → 事实审计 → 保留有利身份暗示 → 补真实缺口`
