# ZWM · AI 工作台

这是 ZWM 的公开个人主页仓库，由 GitHub Pages 托管。

访问地址：

https://zwmopen.github.io

## 当前设计

- 风格：柔和拟态 / Neumorphism
- 主题：浅色与深色双主题
- 页面：个人定位、四层工作系统、公开项目、当前主线与构建原则
- 适配：桌面、平板与手机
- 交互：固定导航、平滑滚动、主题切换与本地偏好保存

## 页面表达

主页围绕以下协作闭环展开：

> 真实需求 → AI 协作 → 人工验收 → 资产沉淀

系统结构包括：

- 判断层：业务 SOP、质量标准、复盘和人机协作
- 执行层：可被 AI 工具直接调用的 Skill
- 工具层：公开脚本、本地应用和批处理
- 项目层：团建内容、视频素材与具体产品

## 文件

- `index.html`：完整页面、样式、响应式布局和主题交互
- `.nojekyll`：按纯静态站点发布，不经过旧 Jekyll 模板

## 维护规则

1. 本仓是线上发布入口。
2. 私有设计镜像为 `zwmopen/xiangruiai-like-homepage`。
3. 两个仓库的 `index.html` 应保持相同内容哈希。
4. 页面项目链接变化时，同步更新仓库治理注册表。
5. 不在主页中公开私有仓库地址、客户数据或个人密钥。
