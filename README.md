# ZWM · AI 工作台

这是 ZWM 的公开个人主页与在线产品入口，由 GitHub Pages 托管。

访问地址：

https://zwmopen.github.io

## 当前定位

- 公开展示：个人定位、工作系统、公开项目、真实应用与最近更新
- 在线工具：MD2Card Studio、OwlReader Next
- 风格：柔和拟态 / Neumorphism，支持浅色与深色主题
- 适配：桌面、平板与手机，手机端提供固定快捷导航
- 原则：公开入口与私有业务数据严格分离

## 页面结构

1. 首页：个人定位与主要入口
2. 在线工具：优先提供可直接使用的网址
3. 工作系统：判断层、执行层、工具层与项目层
4. 公开项目：展示形态、能力和真实成果
5. 应用案例：说明工具如何进入真实工作
6. 最近更新：公开维护节奏与项目变化
7. 构建原则：单一事实源、本地优先、人掌握判断、结果优先

## 文件

- `index.html`：主页、样式、响应式布局、主题交互与结构化数据
- `icon.svg`：站点图标
- `og-card.svg`：社交分享卡片
- `sitemap.xml`：主页与在线工具索引
- `robots.txt`：搜索引擎抓取策略
- `404.html`：自定义错误页
- `.nojekyll`：按纯静态站点发布

## 维护规则

1. 本仓是线上发布入口。
2. 私有设计镜像为 `zwmopen/xiangruiai-like-homepage`。
3. 不在主页中公开私有仓库地址、客户数据、个人记忆、令牌或密钥。
4. 新增公开工具时，同步更新主页工具区、最近更新和 `sitemap.xml`。
5. 在线入口优先于源码入口；只有实际可用的项目才标记为 `ONLINE`。
